# 图标选型预览

本文是 [SKILL.md](SKILL.md) 第 1 节的预览做法,与 SKILL.md 正文同等强制;何时读取见该节。

- 预览用 Artifact 页(先按 `artifact-design` skill 校准,做成克制的功能性对比页)。
- 候选**用图标库真实 SVG 渲染**——照抄官方内部元素,不得用文字描述代替:选型看的是字形,描述传不出字形。
- 按该图标在界面里的**实际几何**摆放(容器宽度、行内边距、按钮盒尺寸、图标 size),并把相邻元素(角标、选中态、相邻按钮)一并放进去——图标在空白页上都好看,挤在真实行里才看得出干扰。
- 深浅色并排;成组图标必须并排看协调度。
- 每个候选给一句语义说明,标出推荐项。
